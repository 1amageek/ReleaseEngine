# ReleaseEngine Fixtures

The signoff and tapeout smoke corpus is generated by `ReleaseEngineBehaviorTests` so every artifact is written under a temporary project root and its SHA-256/byte count is recorded before evaluation.

Covered fixture classes:

- complete digital signoff with profile-approved not-applicable axes;
- missing typed evidence;
- expired scoped waiver;
- complete GDSII stream-out and exact-stream handoff;
- tapeout without stream-out prerequisites.

Fixtures intentionally exercise project-relative paths and immutable references. They do not encode a process qualification claim.

Release authorization fixtures are generated by `ReleaseAuthorizationTests` because authorization binds exact artifact digests, byte counts, human approval, and independently persisted ToolQualification decisions. Keeping synthetic fixed-digest authorization JSON would weaken that integrity contract.
